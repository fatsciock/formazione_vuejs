Sezione 3 — Operatori, Condizioni e Cicli (2h)

Usa questo file con VS Code + Live Server. Apri la Console del browser (F12 → Console) per eseguire gli esempi. Tutte le sezioni sono commentate: sblocca (rimuovi //) le righe che vuoi far eseguire in aula.

1. Operatori aritmetici (15 min)

+, -, *, /, %, ** e ++/--

2. Operatori di confronto (15 min)

>, <, >=, <=, ==, ===, !=, !==

3. Operatori logici (15 min)

&& (AND), || (OR), ! (NOT). Concatenare condizioni per decisioni composte.

4. Strutture di controllo (30 min)

if / else / else if e switch con case e break.

5. Cicli (30 min)

Concetto: ripetere un blocco di istruzioni. Esempi: for, while, do...while, for...of, for...in.

6. Esempi pratici e esercizi (15 min)

Prova gli esercizi in console sbloccando le funzioni qui sotto.

Suggerimento didattico: sblocca e fai eseguire un esempio alla volta, poi chiedi agli studenti di modificarlo (cambiare limiti, aggiungere casi, usare for...of, ecc.).
