## 1. Array e oggetti

### Array
- Cos'è un array
- Array misti
- Sintassi
- Comandi (pop, push, splice)


#### Esercizi
- Script che calcola media di un array, min, max. Dividerlo in funzioni
- Metodo che verifica se un elemento è presente in un array

### Oggetti
- Cos'è un oggetto (raccolta di coppie chiave-valore)
- in altri linguaggi è un dict
. sintassi ({} per crearlo, dict.proprietà per leggere/modificare una proprietà)
- delete per cancellare proprietà

#### Esercizi
- Crea un oggetto libro (titolo, autore, anno di pubblicazione, generi (è una lista), prezzo)
- Stampa le sue informazioni
- Aggiungi una proprietà pagine e stampala
- Modifica la proprietà anno
